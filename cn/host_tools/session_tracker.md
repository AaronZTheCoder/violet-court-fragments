## 零回检查清单

在战役开始前使用此清单。确保玩家和主持人在游戏的基调、内容和期望上达成一致。

**战役设定：**
[ ] 讨论战役基调：恐怖、悲剧、行动，或是三者平衡
[ ] 解释帝国背景：调和、六大学派、十大人物
[ ] 描述赤暮及其对世界的意义
[ ] 设定角色死亡与替代的预期
[ ] 讨论长期战役结构（预期回目数、终局目标）

**角色创建：**
[ ] 每位玩家选择命格并解释其选择
[ ] 每位玩家定义角色与十大人物之一的羁绊
[ ] 每位玩家确立一个与战役相关的个人目标
[ ] 队伍决定角色们如何相识
[ ] 玩家设定起始调和度（默认 50）
[ ] 根据命格分配起始真气和心神

**内容与安全：**
[ ] 讨论内容边界。哪些话题应避免或一笔带过？
[ ] 建立玩家需要场景停止时的信号（安全词或手势）
[ ] 讨论大家都能接受的描述性暴力程度
[ ] 讨论赤暮腐蚀主题和身体恐怖界限
[ ] 确认玩家是否希望有浪漫副线，以及详略程度

**房规：**
[ ] 确认任何房规或桌上规定
[ ] 决定投骰风格（公开投骰、主持人暗骰、仅玩家投骰）
[ ] 设定玩家知识与角色知识的预期
[ ] 讨论日程安排和回目时长
[ ] 决定回目间的沟通方式

## 幕间检查清单

每回跑团结束后审阅，为下一回做准备。

**审阅：**
[ ] 阅读跑团笔记并更新任何未完成的条目
[ ] 检查玩家角色表的变化（气血、真气、心神、调和）
[ ] 检查势力立场变化并规划反应
[ ] 审阅玩家做出的决策并规划后果
[ ] 检查已揭晓秘密列表并准备下一批揭露
[ ] 审阅受喜爱的非玩家角色并规划其下一次登场
[ ] 阅读角色历程笔记并考虑如何推进每个玩家的故事

**准备：**
[ ] 规划下一回的开场场景
[ ] 准备可能发生的赤暮遭遇
[ ] 记录哪些势力行动将在幕后发生
[ ] 准备回归非玩家角色的对话或举止特征
[ ] 确定玩家可能面对的两到三个重大决策
[ ] 准备任何未解线索的后果
[ ] 规划一个赤暮现象，在队伍进入赤暮领地时引入

**推进世界：**
[ ] 酌情推进暮色阶段时钟
[ ] 确定是否有州府沦陷于赤暮
[ ] 决定十大人物中是否有谁行动或改变了
[ ] 记录政治格局的任何变化
[ ] 用已过天数更新战役时钟

**个人准备：**
[ ] 重读即将到访地点相关的任何传说或笔记
[ ] 练习关键非玩家角色的语音或举止特征
[ ] 准备下一回的讲义、地图或道具
[ ] 游戏日前睡个好觉

_每回跑团打印一份。妥善保管填写完毕的记录表，它们将成为战役的编年史。_
