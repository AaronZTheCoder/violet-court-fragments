# 桌面速查

## 桌面速查卡

### 核心判定

**d20 + 属性修正值 + 熟练加值（如适用）对抗目标值**

| 目标值 | 难度 |
| ------ | ---- |
| 5      | 简单 |
| 8      | 常规 |
| 12     | 中等 |
| 16     | 困难 |
| 20     | 艰巨 |
| 24     | 传奇 |

### 优势与劣势

优势：投2d20，取较高值。
劣势：投2d20，取较低值。
两者相互抵消。

### 重击

自然20：大成功。获得非凡效果。
自然1：大失败。触发意外状况。

### 战斗回合

1. **行动：** 攻击、技法、防御、协助、即兴
2. **移动：** 一个区域（或起身、寻找掩护）
3. **自由互动：** 说话、拔武器、拾取物品

### 濒死

生命值归零时：每回合进行韧性检定，目标值15。
三次失败先于一次成功 = 死亡。
稳定伤势：智力检定目标值12，需医疗用品或治疗。

### 区域

- 每回合移动一个区域
- 近程：同一区域或相邻区域
- 远程：两个区域（劣势）

### 社交行动

- 说服：改善立场
- 欺骗：令人信服地撒谎
- 探查：了解目标动机
- 施压：强迫服从（立场恶化）
- 坦诚：分享真相（自动提升1级立场）

### 和谐值

0-20 异端（即将被调查）
21-40 可疑（无权任职，信件被检查）
41-60 可接受（正常，审查中易受牵连）
61-80 和谐（受保护，有晋升资格）
81-100 典范（受庇护亦成目标）

### 休息与恢复规则总结

| 休息类型 | 时长                   | 效果                                                                                               |
| -------- | ---------------------- | -------------------------------------------------------------------------------------------------- |
| 短休     | 1小时                  | 恢复韧性修正值等量真气（至少1）。可消耗生命骰（如使用可选规则）恢复生命值。移除1级疲惫。           |
| 长休     | 8小时（至少6小时睡眠） | 恢复全部真气。恢复全部生命值。移除所有疲惫。移除一级力竭。移除一级赤暮腐蚀（自然恢复，无需治疗）。 |
| 深度冥想 | 1小时（可中断）        | 恢复 1d4 + 智力修正真气。每休憩一次。需安静环境且无战斗。                                          |

**治疗与恢复：**

- 伤口：绷带和基础急救（智力目标值12）恢复 1d4 生命值。每处伤仅一次。
- 赤暮腐蚀治疗：每级需智力目标值16和24小时休息。气术（赤暮净化）可加速。
- 心神恢复：自然恢复（安全地点长休）每日恢复1点心神。受信赖非玩家角色的心理咨询或治疗每回恢复 1d4 心神。完成角色目标恢复 2d6 心神。
- 中毒或疾病：需智力目标值14及适用工具包治疗。未经治疗的中毒或疾病每24小时恶化。

### 六大学派一览

**金玉正宗**
核心理念：古法不可废。变化即腐化。
关键人物：朱砂心
立场效果：立场高则免受审核和调查。立场低则引来审查官的关注。
典型成员：史官、传统主义者、保守派官吏、长老。
对立学派：明镜（对传统纯正性之争议）、翠微之道（对变革之争议）。

**翠微之道**
核心理念：适者生存。世界在变，我们亦须应变。
关键人物：林间客
立场效果：立场高可获得珍稀药草、毒药和疗法。立场低则医者和草药师拒绝服务。
典型成员：医者、炼金术士、农夫、生存主义者。
对立学派：金玉正宗（对变革之争议）、赤血传承（对自然秩序之争议）。

**铁算学派**
核心理念：万事皆可计算。效率为最高美德。
关键人物：铁算子
立场效果：立场高则商品、服务和信息降价。立场低则引发经济制裁和抬价。
典型成员：商人、会计、战略家、后勤人员。
对立学派：民火（对人伦与数字之争议）、赤血传承（对贵族特权之争议）。

**赤血传承**
核心理念：血脉记得帝国强迫自身遗忘之事。
关键人物：永夜公爵
立场效果：立场高可进入贵族法庭和上流社会。立场低则被社交活动和贵族合作排斥。
典型成员：贵族、血脉史研究者、继承记忆的研究者。
对立学派：民火（对等第之争议）、明镜（对纯粹之争议）。

**民火**
核心理念：权力属于人民，而非少数。
关键人物：铁骨
立场效果：立场高获得情报网络、安全屋和群众支持。立场低则流言蜚语转为敌意，人群变得危险。
典型成员：平民、劳动者、革命者、地下领袖。
对立学派：赤血传承（对贵族之争议）、铁算学派（对剥削之争议）。

**明镜**
核心理念：纯粹至上。赤暮是必须净化的污渍。
关键人物：明镜
立场效果：立场高获得真气训练机会和圣物研究特权。立场低则被标记为净化和调查目标。
典型成员：气术大师、苦修者、净化者、调查官。
对立学派：金玉正宗（对纯粹定义之争议）、赤血传承（对血脉纯粹之争议）。

**势力立场效果总结：**

- 景仰（80+）：学派主动保护并提拔角色。获得精英资源。可能获得与关键人物的亲自会面。
- 信赖（50+）：学派视角色为宝贵盟友。折扣、信息共享、小恩惠。
- 青睐（20+）：学派对角色观感正面。基本合作。标准服务可用。
- 中立（0）：无特殊待遇。标准互动。无敌意但无帮助。
- 可疑（-20）：学派保持警惕。服务受限。角色可能被监视。
- 敌对（-50）：学派积极对抗角色。被拒服务。可能存在暴力风险。
- 不共戴天（-80+）：学派投入资源以毁灭角色。刺客。黑名单。公开敌对。
