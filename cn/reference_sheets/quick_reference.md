# 桌面速查

## 桌面速查卡

### 核心判定

**d20 + 属性调整值 + 熟练加值（如适用）对抗目标值**

| 目标值 | 难度 |
| ------ | ---- |
| 5      | 简单 |
| 8      | 常规 |
| 12     | 中等 |
| 16     | 困难 |
| 20     | 艰巨 |
| 24     | 传奇 |

### 优势与劣势

优势：投2d20，取较高值。
劣势：投2d20，取较低值。
两者相互抵消。

### 重击

自然20：大成功。获得非凡效果。
自然1：大失败。触发意外状况。

### 战斗回合

1. **动作：** 攻击、使用技法、防御、协助、即兴
2. **移动：** 一个区域（或起身、寻找掩体）
3. **自由交互：** 说话、拔出武器、拾起物品

### 濒死

生命值归零时：每回合进行韧判定，目标值15。
在首次成功前累计失败三次：死亡。
稳定伤势：智判定目标值12，需医疗用品或治疗。

### 区域

- 每回合移动一个区域
- 近程：同一区域或相邻区域
- 远程：两个区域（劣势）

### 社交态度

| 态度 | 说服目标值 |
| ---- | ---------- |
| 敌对 | 20         |
| 怀疑 | 16         |
| 中立 | 12         |
| 接纳 | 10         |

### 社交行动

- 说服：改善态度
- 欺瞒：令人信服地撒谎
- 试探：了解目标动机
- 施压：强迫服从（态度恶化）
- 坦白：分享真相（自动提升1级态度）

### 和度刻度

0至20 异端（即将被调查）
21至40 可疑（无权任职，信件被检查）
41至60 合格（正常，清和巡察中易受牵连）
61至80 和谐（受保护，有晋升资格）
81至100 楷模（受庇护亦成目标）

**治疗与恢复：**

- 稳定伤势：使用适当物资并通过目标值12的智判定，可稳定濒死角色。治疗技法或治疗物品也能做到。
- 医疗诊治：医师照料价格为5银，恢复1d4生命值并提供持续照料。
- 神智恢复：与他人进行有意义的交流恢复1d4神智，完成重大目标恢复1d6神智。
- 中毒或疾病：净体可移除一种毒素、疾病或轻度赤暮污染。解毒剂则使对抗摄入毒素的坚韧检定获得优势。

### 成长点速查

角色通过经历成长。主持会在每段重要剧情或每次集会结束时发放成长点：

| 成就                 | 成长点 |
| -------------------- | ------ |
| 完成一次集会         | 1      |
| 完成一个重大目标     | 2      |
| 解决一个主要故事段落 | 3      |
| 出色的角色扮演或巧思 | 1      |

**使用成长点：**

| 成长项目                  | 成长点消耗 |
| ------------------------- | ---------- |
| 某项属性增加1点（上限20） | 3          |
| 获得一项新技能熟练        | 5          |
| 习得一项新技法            | 4          |
| 气海上限增加5点           | 3          |
| 从原型树获得一项特殊能力  | 5          |
| 熟练加值提升（每4级）     | 自动       |

**等级：** 角色的等级等于已消耗成长点总数除以4，向下取整，再加1。

| 等级 | 已消耗成长点 | 熟练加值 |
| ---- | ------------ | -------- |
| 1    | 0 至 3       | +2       |
| 2    | 4 至 7       | +2       |
| 3    | 8 至 11      | +2       |
| 4    | 12 至 15     | +2       |
| 5    | 16 至 19     | +3       |
| 6    | 20 至 23     | +3       |
| 7    | 24 至 27     | +3       |
| 8    | 28 至 31     | +3       |
| 9    | 32 至 35     | +4       |

九级是角色档案所列进阶树的上限。若游戏继续升至更高等级，熟练加值沿用第五章的进程：至十二级为+4，至十六级为+5。

### 六大学派一览

**正宗**
核心理念：古法不可废。变化即腐化。
关键人物：丹心
派系立场效果：派系立场高则免受清和巡察与调查。派系立场低则引来审查官的关注。
典型成员：史官、传统主义者、保守派官吏、长老。
对立学派：明镜（对传统纯正性之争议）、青道（对变革之争议）。

**青道**
核心理念：先疗愈土地，才能疗愈帝国。帝国从来不是自然之外的存在。
关键人物：林间客
派系立场效果：派系立场高可获得珍稀药草、毒药和疗法。派系立场低则医者和草药师拒绝服务。
典型成员：医者、丹师、农夫、生存主义者。
对立学派：正宗（对变革之争议）、赤脉（对自然秩序之争议）。

**铁算**
核心理念：万事皆可计算。效率为最高美德。
关键人物：铁算
派系立场效果：派系立场高则商品、服务和信息降价。派系立场低则引发经济制裁和抬价。
典型成员：商人、会计、战略家、后勤人员。
对立学派：民火（对人伦与数字之争议）、赤脉（对贵族特权之争议）。

**赤脉**
核心理念：血脉记得帝国强迫自身遗忘之事。
关键人物：永夜公
派系立场效果：派系立场高可进入贵族法庭和上流社会。派系立场低则被社交活动和贵族合作排斥。
典型成员：贵族、血脉史家、研究传承记忆的人。
对立学派：民火（对等第之争议）、明镜（对纯粹之争议）。

**民火**
核心理念：权力属于人民，而非少数。
关键人物：铁骨
派系立场效果：派系立场高可获得情报网络、安全屋和群众支持。派系立场低则流言蜚语转为敌意，人群变得危险。
典型成员：平民、劳动者、革命者、地下领袖。
对立学派：赤脉（对贵族之争议）、铁算（对剥削之争议）。

**明镜**
核心理念：纯粹至上。赤暮是必须净化的污渍。
关键人物：明镜
派系立场效果：派系立场高获得天炁训练机会和圣物研究特权。派系立场低则被标记为净化和调查目标。
典型成员：天炁大师、苦修者、净化者、调查官。
对立学派：正宗（对纯粹定义之争议）、赤脉（对血脉纯粹之争议）。

**派系立场效果总结：**

- 景仰（80+）：学派主动保护并提拔角色。获得精英资源。可能获得与关键人物的亲自会面。
- 信赖（50+）：学派视角色为宝贵盟友。折扣、信息共享、小恩惠。
- 青睐（20+）：学派对角色观感正面。基本合作。标准服务可用。
- 中立（0）：无特殊待遇。标准互动。无敌意但无帮助。
- 可疑（-20）：学派保持警惕。服务受限。角色可能被监视。
- 敌对（-50）：学派积极对抗角色。被拒服务。可能存在暴力风险。
- 不共戴天（-80+）：学派投入资源以毁灭角色。刺客。黑名单。公开敌对。
