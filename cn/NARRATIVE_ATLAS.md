# 紫宸残卷

## 叙事全图

供主持使用。本图将既有设定、故事与规则接成一部持续的残卷，是查阅工具，不另设一场冒险。配合[战役衔接手册](CAMPAIGN_CONTINUITY.md)、[主持人法典](HOST_CODEX.md)、[设定书](GAME_DESIGN.md)与[核心规则书](CORE_RULEBOOK.md)使用。

节点是能因游戏行动而改变的情境。上位条件说明它为何相关；回返之物可以是人、资源、记录或承诺，将结果带向别处。队伍可以拒绝、解决、重访，或走出表中没有列出的路。按实际发生的事记录，不强迫进入下一节点。

### 核心问题

帝国依赖土地、劳动、粮食、运输、天炁、信用、庇护、律法与共同记录存续。同一张网络既能保护人，也能决定谁的损失被计算。赤暮伤害网络中的地方。肇建与后来的封印都留下有据可查的伤害，赤暮的完整成因与本质仍未确定。

谁能够被看见、得到帮助，并参与决定以自己名义作出的承诺？求粮的人家、争取安全工钱的工人、保护姓名的幸存者，以及考虑同意与否的主祀者，都能面对这个问题，不必共享一桩秘密，也不必属于同一事业。

### 九域及其联系

九域是历史地理区域。州、府与县是行政单位，可以分设或撤销；居留码被撤，不使土地与人民消失。前五域沿用设定书，后四域根据已有地点与历史，补足此前未命名的区域。

| 域       | 社群与资源                           | 共同残卷中的联系                               |
| -------- | ------------------------------------ | ---------------------------------------------- |
| 京畿     | 霄垣、银渡、和宁关、记录与信用       | 被收下的请求可以改变地方拨付                   |
| 东冶     | 烬炉、齿轮之心、工班、机械与天炁器具 | 修缮依赖工钱与核准的配置                       |
| 南仓     | 玉阶、静湾、稻粮、丝与运契           | 供粮世家及其脚力须面对递送结果                 |
| 西垒     | 天柱要塞、铁门关、堡垒与护送         | 车队需要保护，也需要有人接收                   |
| 北茫     | 青根、空谷、森林、药材与水源         | 勘路须依靠当地知识，并取得社群同意             |
| 西原     | 烬原、牧户、牲畜与烟熏乳酪           | 流离人家需要身份承认与运输                     |
| 琥珀海域 | 琥珀海岸、渔村、盐与海上联系         | 幸存者证言可以支持请求，同时不暴露庇护所       |
| 东谷     | 九柳湾、河谷乡里与地方文字           | 姓名、水源和补偿将呈状接回仍在生活的人         |
| 盐原     | 牧站、牲畜、皮革与内陆路线           | 铁笔少年牧站的经历，使官定故事有可问的人与地方 |

烬原与琥珀海岸是已经沦陷的边州；泣谷与终门仍在。终门既是要塞城，也是周边府县的名称。九柳湾是被划除的东谷府县。现有记录尚未确定泣谷与终门分属于哪一域；真正需要边界时，可由全桌建立。

### 联系示意图

以下说明已有方向与路线，不按比例绘制，也不虚构所有边界。

北茫 → 林木、药材、水源知识 → 霄垣

东冶 → 机械、工班、轨路 → 霄垣

南仓 → 粮食、丝、运契、轨路 → 霄垣

霄垣 → 限制使用的轨路 → 西垒

西垒 → 护送与地方道路 → 铁门关及边境山口

西原与琥珀海域 → 流离者与请求 → 接收处与霄垣

东谷 → 九柳湾、水源与证言 → 呈状与庇护

盐原 → 牧道与服役记忆 → 地方交代

霄垣 → 拨付、信用、律法与诵述 → 各域可抵达的官署与能运作的灯驿

玉河与御道在银渡交会，和宁关检查进京货物，铁门关设有公共灯驿。各支流与截江大堰的精确位置尚未确定；处于同一水系，不自动证明两地有直航路线。

已有三条轨路，从霄垣通往东冶、南仓与西垒；尚无记录表明轨路终点就在铁门关。轨行至东冶约两日，普通驿递约三日。霄垣至终门的普通驿递单程约两周。公共灯驿传递定时播送与短报，受损时可能中断；成对天炁共振塔能即时密传，费用极高。选择取决于路程之前，须说明容量、认证与时间。

### 叙事树

箭头代表可以走通的联系，不是必经顺序。各节点说明上位系统、进入情境、选择及可带回的结果。

#### 开篇

**R0 持续生活的帝国。** 上位：S1至S8。某人或某地需要网络能够提供的东西。队伍决定在乎什么、愿意做什么。即使离开，相关人仍会行动。

**A0 递送或另一种开始。** 上位：R0、S2、S3、S8。苇篓提出二十七号恤册，或队伍遇见同一情境中的人。可以递送、修订、议价、拒绝或另寻道路。两份抄本、失踪人家与收件处可以回来。

**A1 粮仓。** 上位：A0、S2、S4、S5。粮已到，转运处却缺发放令。可以寻签、使用现成急赈权限、另筹物资、承担擅发风险或离开。保留脚夫、庙中办事人、粮与实际批令。

**A2 证人与储备。** 上位：A0或A1、S2、S3、S4、S7。林为陈涛寻求保护。可以提供庇护、护送、代理或别的安排，也可独立查账。陈涛付款抄件与张的储备证据是不同来源。被挪天炁影响配置，不为巡察供能，也不确立赤暮成因。

**A3 巡察。** 上位：A2或实际传唤、S3、S4、S6、S8。孟依据可得账目与指控办案。可以证明亲知事实、质疑、寻求庇护或代理，也可以在了解后果后缺席。带回被收下的证据、裁断与经手人；基础风险只计一次。

**A4 共账。** 上位：A0或A1、S3、S5。流转签或收存簿将赈济连到已排定的典礼。可以核验附页、争取分账或暂缓，也可以让条款继续。发放令与暂录名册是两份记录。

**A5 附款与壁龛。** 上位：A4、S4、S5、S7。纳祀附款拟将今后的分派权交给天廷。可以修订、同意、质疑或不介入。香冠与所选代表各自决定。保留实际措辞、见证与典礼结果。

**A6 开篇有结果。** 上位：A1至A5中的任一项。按实际行动处理赈济、名册与同意；队伍未介入时，也记录官员和受影响的人各自做了什么。再回到承受结果的人身边。更大的谜题不会抹掉已经送出的粮、收下的请求或拒绝的同意。

#### 劳作、水与土地

**W1 工班条件。** 上位：A1或A2、S2、S6。脚力或修缮工班需要工钱、粮、工具与安全。可以交涉、另提办法或拒绝。约定随人和器具继续。

**W2 受损路线。** 上位：W1，或直接旅行、地方报告；S1、S2。道路、灯驿或水工不安全。可以勘查、改道、修缮、撤离或等待。带回注明日期的观察与实际限制。

**W3 淤沙文书。** 上位：W2、S3、S7。勘查触及旧水政。可以读档、寻见证、比对来源，或先做眼前工作。带回证据与受忽视影响的人。

**W4 截江大堰。** 上位：W3或请求者、S1、S2、S4、S6。有人请求补偿、水或动力。可以核验承诺、交涉、争取修复或质疑工程。大堰的收益与迁出的代价都继续成立。

**W5 旧路。** 上位：W2、S1、S7。林木或道路勘图触及林间客曾帮助开出的路。可以比图、询问当地社群、保护通行或改变工程。她的记忆不能取代当地人的同意。

#### 姓名与庇护

**N1 暂录名册。** 上位：A0或A4、S3、S7。一户人家被列为确认、失踪或存疑。可以提交有依据的条目、注明不确定、征询同意或保密。记录谁持有收讫件。

**N2 撤销的居留码。** 上位：N1、S3、S4。烬原或琥珀海岸幸存者无法使用旧码。可以争取暂认、纠正登记、使用见证或保护私下路线。获得门路不等于逆转地方沦陷。

**N3 骨上的名字。** 上位：N1或N2、S3、S7、S8。骨书或另一位呈状人带来姓名。骨书尚未公开重构条目中的不确定之处；信任与事件发展后，由他选择是否透露。可以核实一部分、保护持有人、请求入册或对公开与否提出异议。分清已同意分享与仍属私密的姓名。

**N4 庇护。** 上位：N1至N3，或任何人眼前的庇护需求；S4、S5。可以请求庙方或别处庇护、交涉条件或另寻办法。记录同意、承诺界限及谁知道地点。

**N5 炊烟。** 上位：N3与可信来源、S1、S7。骨书听商旅说有人回到九柳湾。可以保护消息、征得同意后查访、比对证言或不打扰社群。一处有人生还，不证明所有赤暮区安全。

**N6 重叠文书。** 上位：N1、N2或旅途、S3、S4。逸笔的核发文书或另一张路凭帮助过关。可以使用、核验、保密或纠正登记。官署核发的文书也可能含有虚假申报；对铜勺的伤害仍是一项未尽责任。

#### 权柄与记忆

**P1 重修。** 上位：A4、S3、S4、S7。请求受到语域或结账条款影响。可以比对措辞、取得释令、争取暂缓或质疑解释。记录具体改变的条款与执行者。

**P2 公开的交代。** 上位：A5或P1、S5、S6、S7。掌册之手的纪念传到记得另一版本的人那里。可以保护证人、比较四二三年诵述、争取承诺或让典礼继续。指出具体听众与传递者。

**P3 宪章。** 上位：P1、P2或自选查究、S3、S4、S7。影子持有一份副本，天书可以帮助追溯来历或寻找其他存本。可以鉴定、保护、有限公开、交易或暂不公布。保留可得证据真正证明的内容。

**P4 伪诏。** 上位：P3或独立证据、S3、S4、S7。工坊记录、证人或字迹引出问题。可以核查来历、保护工人、质疑特定命令或请求听证。一份伪诏不能证明所有诏令皆伪。

**P5 封闭之门。** 上位：P3、P4、已排定的绵延之仪或主祀者的请求；S1、S5、S7。仪典、证人或自选调查触及永曙塔。可以维护绵延之仪、质疑说法、交涉查阅或另寻记录。带回观察、同意与事前已知的风险；绵延之仪与全礼不同。

**P6 受损的通道。** 上位：P5与独立证据、S1、S7。肇建与封印记录可与亲历比较。可以检验解释、寻找另一成因、尝试修复，或在未解谜时先保护人。献祭方案需要证据与知情同意，不是必然答案。

#### 可以得到的结果

**E1 受到保护的地方。** 上位：W、N或P。说明谁能使用路线或庇护所、由谁维护，以及什么仍脆弱。

**E2 改变的机构。** 上位：P1至P4或W4。记录具体条款、拨付或程序，以及执行和有能力行动的反对者。

**E3 联合或分道。** 上位：W1、N4、P2或P3。明确协议及其界限。各方可以在一件事上合作，在另一件事上分歧。

**E4 离开或承接。** 上位：任何自选分支。角色可以离开、退隐、死亡或交托工作。依核心规则书，经可信联系处理传承。逃离不自动结束玩家角色，也不抹去所有关系。

**E5 更大的对峙。** 上位：已建立的地方压力与全桌选择。使用实际联盟、准备、证据与暮况。都城沦陷、最终敌人和角色献祭都是可能，不是条件。

### 地方分支

每条分支都可以从旅行、请求，或已认识的人带来的消息开始，不要求先完成另一处地方故事。

**L1 都城门径。** 上位：S2、S3、S4；A0或直接旅行。脚力抵达和宁关、银渡、外市或霄垣官署。可以验路凭、谈费用、追查消息或另寻入口。带回收货的人与经手登记的权限。

**L2 东冶班次。** 上位：S1、S2、S6；W1或工班请求。修缮抵达烬炉、齿轮之心或算库。询问工人需要什么器具与条件，争取规划官批准，或先做较小的修理。带回机械状况与工班协议。

**L3 南仓粮运。** 上位：S2、S4、S6；A1或供粮人请求。粮经过玉阶、静湾或村落。可以交涉运费、核验数量或争议损耗。带回供粮人家、脚力与收讫件中写明的责任。

**L4 西垒通路。** 上位：S1、S2、S4；W2或车队。路线抵达天柱要塞、静默寺或铁门关。可以寻护送、询问山口、发送灯驿短报或改变行程。带回实际使用的路与沿路的人。

**L5 林中集会。** 上位：S1、S2、S7；W5或社群邀请。勘查抵达青根、微光之池或空谷。听当地交代、请求进入或退出。带回人们同意分享的内容及附带义务。

**L6 西原请求。** 上位：S1、S3、S7；N2或牧户请求。烬原人家需要牧地、文书或寻找亲属的门路。可以比对证言与可得记录、支持请求或保护私路。带回人家的决定与实际资源。

**L7 海域记忆。** 上位：S1、S3、S7；N2或渔人请求。琥珀海岸幸存者带来船册或潮水的经历。可以寻找失踪者、保存技艺，或决定是否分享记录。带回同意、来源与证据尚不能证明的部分。

**L8 东谷姓名。** 上位：S1、S3、S7；N3或河谷社群。水源或居留请求触及九柳湾。可以经同意核验姓名、询问勘查，或保护返回者的消息。带回具体请求及持有人。

**L9 盐原交代。** 上位：S2、S6、S7；P2或牧站需求。驿骑、工人或人家记得铁笔少年时住过的牧站。可以将他们的叙述与诵述比较、交涉物资，或让说法保持私密。带回见证人的决定与使各方相遇的实际需求。

### 其他网络

以下群体原已存在于设定，是既有节点的可能参与者，不是另一张必做清单。群体经已认识的人、具体行动或可信报告进入；成员之间也可能有分歧。

**H1 未闻祷言之秩序。** 上位：S4、S5、S6；P2或P5。仪轨师履职时质疑教义。受保护的交谈或争议文本，可能带来证言、沉默或求安置的请求。

**H2 碎裂之链。** 上位：S2、S4、S6；W1或F9。逃离强制劳动的人互相扶持。路线、工钱争议或营地记录，可能引出护送、请求，或拒绝暴露成员。

**H3 十二柱。** 上位：S3、S7；P3或F10。修史者在暗窟保存副本。来源可以请求安全保管或比对；队伍决定分享什么证据。

**H4 夜之花园。** 上位：S1、S5、S7；N4或P6。成员相信赤暮带来转化。这是一种待检验的立场，不证明其本质；个人可能寻求庇护，也可能招募他人。

**H5 开手社。** 上位：S2、S5、S6；A1或N4。粥棚或诊所可以帮助人家，也可能提出教育门路。是否接受给孩子的机会，由家人决定。

**H6 静步兄弟会。** 上位：S2、S4；W2或N6。驿使共享路线与互助保护。护送或受损消息可以确定通行条件，以及这条路能安全带谁走。

**H7 语苇之环。** 上位：S3、S7；P1或P3。笔吏保存一份被下令销毁的文书。队伍可以安排保管、比对副本或保护来源。

**H8 铁账公会。** 上位：S2、S3、S6；A2或W1。会计为劳动与保护组织起来。受到质疑的余额或处境危险的书吏，可能带来有限交换、工钱协议或拒绝。

静侣与朱笔行也是既有机构线索。前者将掌册之手的监视职权，与练习或记得其调息法的人相连；后者将审读坊与计手之律连到P1、P2及作者付出的代价。两者都不证明每个学派或官员怀有相同意图。

### 人物分支

每条分支都可以从全桌自选关系、已有后果或人物独立行动开始。既有人物的私知不会自动成为队伍所知；相关职业也不将肖像身世强加给玩家。

**F1 丹心与日记。** 上位：A4或P2，S3、S6、S7。一份报告要求他决定公众能看见什么。队伍可以保护来源、比对私记与原件，或请求有限更正。他知道自己查过的玉版与指令，其他诏令的作者仍未确定。带回具体报告与承受其后果的人。

**F2 夜莺与失落的落点。** 上位：A2、A3或自选关系；S4、S7。安置名册列出幸存人家，却缺目的地。队伍可以追查、保护见证，或让他的家人问题保持私密。他追索杀害魏委员的下令者，也可能碰到证据，但不证明两事出自同一人。带回核实的线索或明确的缺口。

**F3 林间客与旧路。** 上位：W2或W5，S1、S2、S7。勘图沿她曾给旅人指过的路线展开。询问如今生活在那里的人愿意接受什么，比较记忆与勘图，或另选路线。带回地方协议、拒绝或新的义务。

**F4 铁算与预测。** 上位：A2、W1或W4；S2、S4、S6。修缮或拨付需要对储备作出假设。队伍可以比对模型与货单、交涉劳动条件，或请求独立计算。预测依赖假设；调节器与日皇的关系尚未确立。带回公开的假设与具体决定。

**F5 铁壁与预案。** 上位：W2、N4或撤离；S2、S4、S5。车队或受威胁的档案使空座行动相关。队伍可以协助保护人和记录、质疑销档安排，或提出另一种保管办法。密封预案不等于已经执行的命令。带回实际撤出的人，以及真正保存或失去的记录。

**F6 明镜与河工。** 上位：W3、W4或听证；S3、S4、S7。他对曹水政监的案件证据成立。他当时已知道有未列账的维护，而这些维护后来与洪灾有关。队伍可以查卷、寻受灾社群，或追问合法裁断之后仍有何责任。永夜公的另一案尚未证成。带回核实的证据与各方接受的承诺。

**F7 影子与灰柳。** 上位：N4、P2或情报请求；S3、S6、S7。九年前影子出售灰柳的位置；她仍在内迁安置中，网络已经离散。队伍可以保护网络中的人、寻找安全方式联系灰柳，或拒绝交易这项消息。影子知道什么，不等于队伍自动取得接触门路。带回当事人的选择与给她的承诺。

**F8 永夜公与守候。** 上位：P3、P5或请求者；S4、S6、S7。见证人追问退隐、破门或最终封印。永夜公可以分清亲见与推断，说明自己的选择。队伍可以寻求佐证、质问他，或保护因旧安排受益或受害的人家。带回证言与他接受或拒绝的责任。

**F9 铁骨与罢工。** 上位：W1、W2或工人请求；S2、S4、S6。工人重提四三零年的安全罢工与更大起事。队伍可以交涉条件、比较产出勘议与幸存者叙述，或支持工人自行选择的行动。铁骨并不已经知道起事被压制的全部原因。带回工场决定及其对劳动者的影响。

**F10 天书与缺页。** 上位：P3、P6或查档请求；S3、S7。一份文书或缺页引出来历问题。队伍可以比对副本、寻找另一位见证，或同意以受限制的查阅保护来源。她精确的回忆不能补回缺页或失去的私人记忆。带回核实记录、仍存缺口或查阅协议。

**F11 骨书与存疑的姓名。** 上位：N2、N3或呈状人的请求；S3、S5、S7。一部分重构姓名可能受到质疑。是否公开不确定之处由骨书决定。队伍可以与幸存者核验一部分、保护私密姓名、争取合法入册或质疑方法。带回人们同意登记的具体内容及仍未确定之处。

**F12 香冠与应答。** 上位：N4、A5或已排定的绵延之仪；S4、S5、S7。封门后的应答四年前改变，此后她仍呈报旧定式。是否及如何分享观察，由她决定。队伍可以保护侍者、比对获准见证的说法，或交涉典仪的行政条件。观察不证明变化的成因。带回实际同意与证言。

**F13 逸笔与铜勺。** 上位：N2、N6或关卡；S3、S4、S7。官署核发的路凭帮助旅途，借用的身份却妨碍了铜勺获释。队伍可以追查此人如今下落、核对冲突登记、提出更正，或由受影响的人决定。更正只改变所指条目，不证明所有衙门立即行动。带回当事人、收讫件或未尽义务。

### 逐节点核查

1. 核对上位事实：日期、地方、规则与先前决定。
2. 确认每个人想要什么、知道什么、能做什么，以及消息怎样传到。
3. 选择之前，说明所需资源、行程、劳动与时间。
4. 分清亲历、文书内容与解释。
5. 提供可信的替代办法，每项既定代价只计一次。
6. 带回改变的人、约定、物件或地方。
7. 比对中英文名称，分清官署、学派与人物。

设定书、场景种子、图鉴与档案，为同一套系统提供更多情境。新场景需要进入缘由与后果，不需要另立战役前提。全桌可以在有意义的结果处收束，也可以沿已建立的关系继续。
