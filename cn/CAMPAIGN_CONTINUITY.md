# 紫宸残卷

## 战役衔接手册

供主持使用。本手册记录同一个持续世界的日程与后果。各典籍提供不同视角，不另立设定。从主持人法典的相连的九域开始，再按需核对日期、线索与承诺。

### 同一桩事，三个问题

**二十七号恤册**用于核发终门急赈粮。万神之庙愿意将庙区辟作赈粮转运处，其发放附页因此被并入第七龛的典仪账。第六次重修则准备允许谐叙司将这本账登记为已经完成的称谢之举，哪怕失踪者仍未查明。

这是两书在实际行动中的联系。典礼可以真切动人，附在它后面的手续也可以伤人。山崩并非人为安排。官员把已有的赈粮转运处并入早已排定的典仪，是因为这样批得快，也容易呈报成效。此后每个衙门都把这项附属关系当成前一处已经核实过的事实。

分开追问三件事：谁能领到粮，谁还留在名册上，谁有权决定万神之庙的纳祀？玩家可以改善其中一项，而不必解决全部。赈济不必等到查出第六次重修的委办者才开始。

### 可以交到玩家手里的三份文书

**流转签。** 队伍接下恤册时，不经检定即可取得。

> 二十七号恤册。终门急赈粮。
>
> 暂录赈济名册附第七龛典仪账。粮秣可先收存庙区，候令发放。
>
> 未结各项于铰链依届时语域结清。

日期与并账关系一望可知。学识或调查检定目标值12，可找到解释结账条款的登记簿，或在不留下查阅者姓名的情况下取得副本。失败会留下问询记录，不会抹去登记簿的存在。

**发放附页。** 旧本写的是“称谢之前，先收姓名”。第六次重修拟用的本子改成“以所收之账，作称谢之据”。下一具文钥下，记为完成的账意味着暂录领粮资格终止。被列作失踪的人不会凭空死亡或消失，但家人会失去一条求助途径。

措辞本身证明风险，不证明每位书吏都有此意。庙区的收存簿与一张实际被驳回的请领单，可以检验条款如何运作。允许玩家把读法与两者对照。

**纳祀附款。** 这是一项独立的行政条款，将日后分派庙中壁龛的权限交予天廷。此前的纳祀，每次都须庙方对具体人选同意；附款要把逐次同意改成常设授权。条款是新增的，可以删去。祝圣一尊塑像，本身不等于交出庙权。

### 把两条线带到一起的人

**苇篓**是边谐司临时书吏，负责整理暂录名册。她姐姐一家在终门失踪。她请队伍保留那一条未结登记，不请他们推翻任何东西。她懂流转与名册，不掌握解释赤暮的秘密。

“我写的是失踪。他们退回来，说尚未查清。我知道没查清。所以才写失踪。”

**枯墨**一百二十八岁，靠高阶廷臣学者可取得的延寿丹药活到今天。他年轻时参与起草广纳之议，能够辨出两份未署印请办文书中照录的登记房笔迹，却不知道是谁要让后来的文书在此时生效。他仍为记得的工作骄傲，也对如今借它名义办的事不安。

“这行是我写的。底下那道指令不是。劳烦把两张纸并着放。”

**香冠**懂庙法，也懂绵延之仪，但尚未见过赈济附页与行政纳祀附款。将文书交给她，她就能判断轻重。她可以提出附条件祝圣，申请暂缓，或请人见证。她有侍从、同道、责任与疑虑。她的决定不是一场等着玩家交出标准答案的考问。

“龛前那个人的名字，我可以念。那一家人的名字，你们还没让我看见，我不能替他们说已经了结。”

若玩家经约定扮演其中一位既有人物，将相关决定交给该玩家，不要再安排一个相同人物在旁代答。

### 错过一场，也能接续的证据

| 需要查明的事                       | 第一条路径   | 独立路径               | 另一条路径             |
| ---------------------------------- | ------------ | ---------------------- | ---------------------- |
| 赈济与典仪共用一本账               | 流转签       | 庙区收存簿             | 苇篓留存的收讫副单     |
| 结账可能终止领粮资格               | 对照新旧附页 | 一张被驳回的暂录请领单 | 发放书吏解释新语域     |
| 两份未署印请办文书沿用相同登记方式 | 比对卷宗记号 | 枯墨辨认照录笔迹       | 无关衙门的普通请办文书 |
| 庙权转移依靠附款                   | 阅读附款     | 庙中此前纳祀的记录     | 一名明镜审官说明异议   |

角色抵达确实存有线索的来源，并采取合理行动，就应得到关键内容。掷骰决定速度、隐蔽程度、额外让步或取走原件的风险，检定前说明利害。失败可以花费时间、引来注意，不能让其他来源一并消失。

相同批注是照录的登记，不证明某位幕后作者操控了十八年的历史。四三四年，它转送的是内部采录证言的请办件；四五二年，它被沿用到包括第六次重修拟稿的一批勾稽文件中。转送书吏没有委办两项政策的权限。玩家能够查明这段经手过程。旧令究竟被有意利用，还是形成了承讹，仍可继续查证，不靠末尾一场讲话替全桌定论。

### 开场：两份抄本

队伍第一次翻看恤册时，可朗读：

> 纸页下半截还潮着。有人在末尾的签字上撒过细沙，墨没干透，就将它折了起来。
>
> 底下还压着一张。相同的栏，相同的日期。头一张写着“失踪”的地方，第二张空着。
>
> 案后的书吏伸出手。“我得拿一份回去。”

问玩家查看哪一份，想弄清什么，交还什么。不要指定他们的感受。苇篓想留一份能用的记录，也怕丢掉差事。主事想在开听堂开门之前把这批件办完。谁都不知道玩家接下来会怎么做。

### 衔接场景：粮仓门前

开听堂致辞之后，或队伍循着流转签查下去时，可在庙区转运处安排此景：

> 仓门敞着。午后的光落在粮尘里。一名脚夫坐在粮袋上，孩子靠着他的肩睡着了。
>
> 案前的庙祝将请领单翻过来。“这是典仪收据。”
>
> “是他们叫我们来这儿的。”脚夫说。
>
> “我信。”她把单子放在簿册旁。“可我还缺发放令。”

粮食就在眼前，转运处却没有有效的发放令。角色可以争取副署、寻找已有的急赈权限、购买或借用粮食、为未经授权的发放具名担责，也可另想办法。说明各条路由谁批准，承担什么风险。偷取一袋能救一户，也可能牵连脚夫；一张合法批令能惠及所列各户。两种行动都不限定职业。

若玩家不介入，庙祝会递交普通呈请。这需要时间。下次队伍问起时，告知进展，不用一场灾难责罚他们。

### 让路程确实走得通

霄垣至终门，普通驿递单程约两周。不要许诺队伍能从容来回、赶在铰链前返京。实地队伍可从铁门关的公共灯驿传回暂录名册，原件再随驿使送达。启程前明确该站的容量与认证传送费用，由京中盟友代为递交收讫件。留在霄垣的队伍可查访抵京见证人、派出勘查队，或争取展期。

天炁灯驿经有人值守的驿站，播送排定的公开诵述与短报，不是私人对话网络。昂贵的成对天炁共振塔承担即时密讯。邸报可以先到，密封原册仍在路上。

### 会改变下一段故事的选择

| 按现表照章办件     | 保住俸给与职位         | 若无人取得修订，账目照常结清；待领者仍可申请复核 |
| 登记暂录名册       | 所列各户保有具名请求   | 队伍须保护见证人，并如实标明不确定处             |
| 取得庙区发放令     | 令中所列各户领到粮     | 香冠据此要求赈济另立一本账                       |
| 争取暂缓结账       | 铰链期间仍可继续赈济   | 对手可以申驳；祝圣另按自身条件推进               |
| 揭露被改动的告白   | 某一群听众不再相信指控 | 具体驿使或持印者可能转而相助，不保证举国关注     |
| 删改或拒绝纳祀附款 | 万神之庙保留逐次同意权 | 天廷必须交涉、延期，或公开尝试强制               |
| 离开此案           | 队伍可追求别的目标     | 各人物依照手中证据与资源继续行动                 |

笔记中分列三项：**赈济、名册、庙方同意**。记录谁持有效批令，哪些姓名已确认、失踪或存疑，以及庙方究竟同意了什么。时间因旅行与实际办事推进，不为逼出下一场讲话而推进。铰链到来时，结算玩家已经改过的文书，不照搬未经改变的默认结局。

### 将世界带出赈济案

重要选择之后，记下谁看见、哪个机构须回应，以及实际改变了什么。将其中一项带进下一场。这是对已有记录的批注，不另设积分。

若沿**劳作与水源**追问，使用递送中的工班、路线或运契，抵达十五之算、淤沙文书与截江大堰的补偿请求。

若沿**姓名与保护**追问，使用已登场的请求者或证人，抵达烬原撤码、琥珀海岸流离社群，或九柳湾幸存者的同意。骨书尚未分享的私知，仍保持私密。

若沿**权柄与记忆**追问，使用纳祀协议或争议日期，抵达庙中旧档、原始宪章与永曙塔决定的见证人。

各路改变的是对同一帝国能够问什么，不要求都指向同一敌人，也不要求所有人共守一桩秘密。只激活一条已选方向，至多另留一项邀请。

远景仍在，开篇也能结束。为家人、证人或工班留下真实结果，并在视野扩大时保留它。

### 把入门冒险作为可选入口

若使用《初次清和巡察》，在铰链之门月二十一日送来警告，七日后于铰链之槛月三日举行巡察。陈涛原有的证据涉及天炁盗取与此前的巡察，不会突然证明山崩早有预谋。后来一笔合法赈粮拨付也经过同一储备核算处；相关流转签可经书吏、庙方或调卷送到队伍手中。这是继续查访的行政联系，不改写陈涛揭露的案情。

两个入门版本择一使用。两至三次或四至六次集会，都覆盖相同的七个虚构日。玩家可以离京、拒绝学派、救出陈涛，或失去账页原件，仍有其他途径接入后续案件。

### 世界知道多少

肇建与封印有见证者，也有残存记载。它们导致赤暮的说法是一种有力解释，尚非已证实的定律。记录左右赈济与法律身份的效果可直接观察；能否改写现实，仍不确定。天书熟知文献，不等于通晓一切因果。长者对典礼的回忆也可能有误。既有人物的解释是待核查的证据，不是主持公布的最终答案。

让声音出自眼前所求。苇篓要保住一条登记。枯墨分辨自己写下的内容与后来被人利用的内容。香冠分辨同意与服从。铁算要求一套可执行的拨付。明镜追问谁能为命令作证。他们会因面前的人而改变措辞，不需要固定小动作、数字癖好或强加的口头禅来证明自己是谁。
