## 关于本作

**紫宸残卷**是一套完整的纸笔桌面角色扮演游戏规则，适合一位主持人与三至六名玩家。你需要的只是骰子、铅笔、打印好的角色档案，以及一张安静的桌子。无需软件。无需屏幕。只需房间里的人，和你们共同构建的世界。

日皇已有约一百六十五年不曾公开开口。天廷依旧以祂的名义统治帝国。六派学说争夺着一个浩瀚到无人能参透其全貌的官僚体系的控制权。边境之外，一种名为赤暮的现实腐化正缓缓吞噬版图，一州接着一州，将良田化为盐碱，将子民化为泣血的空洞躯壳。天廷称之为"局部性失调"，并派出了清和巡察。沦陷的州府从舆图上被抹去。它们从未存在过。

你可以替天廷抄写文书、护送证人、修缮灯驿，也可以为一户未被计入的人家求粮。选择职业，也选择留在彼此身边的理由。帝国用得着你的活计，是否容得下你，却是另一回事。

**这个游戏的主题，从来不是拯救世界。** 而是在一个浩瀚到无人能参透其全貌的古老体制中，挣扎求存。是在压力中缔结、在命运中经受考验的羁绊。是人们为自我辩护而讲述的故事，以及这些故事崩塌时的景象。

表层是黑暗奇幻。深处是为那些懂得阅读的人准备的。

## 同一个世界，不同的视角

从核心规则书与主持人法典开始。法典卷首现有相连的九域，说明世界的实际联系；《未结之账》则提供可以直接开场的一段故事。玩家需要创角与自选职业机制，主持需要眼前情境及其中的人。

完整典籍仍属于同一部作品。初次清和巡察以紧凑与电影叙事两种方式呈现首次巡察，择一使用。重修说明塑造后果的机构，第七龛让同一批见证与请求进入典礼，战役衔接手册共同记录日期与已经作出的决定。设定书保留更远的历史、地方与谜题。

当前问题抵达哪一处，再读哪一份来源。第一次集会之前，不要求主持先备好所有地域、人物与秘密。

[从主持人法典开始](cn/HOST_CODEX.md)。[查看叙事全图](cn/NARRATIVE_ATLAS.md)。[核对日期与后果](cn/CAMPAIGN_CONTINUITY.md)。

| 铅笔和纸                 | 用于记录、追踪，以及那些不可避免的背叛              |
| 3至6名玩家 + 1名主持人   | 理想的牌桌规模                                      |
| 安静的空间和数小时的时光 | 这不是一场三十分钟的游戏                            |

### 你的第一次集会

1. 以一项主职、一项副业与玩家自选关系创角。
2. 约定为何共同帮助这次递送或这个人，不要求共有预写的过去。
3. 使用法典卷首的开头三场，让受到第一项决定影响的人再次出现。
4. 只留一个当前打算与一项可选邀请，准备下一处能抵达的情境，不列未来战役清单。
5. 开篇有结果后，问全桌想循哪位已认识的人、哪处地方或哪项承诺继续，保留已经挣来的成果。

## 十三大原型

每份档案提供一项主职的能力、衍生加值、装备与成长，并附一位既有人物的可选肖像。玩家自定身世、归属与眼前牵挂。原有数值组保留为人物预设。

其中十二个对应天廷所清点的那十二位重要人物。第十三个对应的是一个天廷始终没能点清的人，而这正是他存在的全部意义。

| 既有人物   | 主职   | 归属     | 人物简介                                                               |
| ---------- | ------ | -------- | ---------------------------------------------------------------------- |
| **丹心**   | 丹师   | 正宗     | 叙事塑造者，深知真相如同一种物质，可以提纯、稀释，偶尔也能掺入毒素     |
| **夜莺**   | 影刃   | 无派系   | 从阴影中出击的专业人士，明白杀戮是第二古老的交易形态                   |
| **林间客** | 长生种 | 青道     | 古老的灵魂，目睹过一个又一个帝国的兴衰，与比天廷更古老的树木交谈       |
| **铁算**   | 机巧师 | 铁算     | 建设者，深知帝国赖以运转的是资源而非教条，而不可替代性本身即是一种权力 |
| **铁壁**   | 壁垒   | 卫戍司   | 向沉默的日皇宣过誓的坚垒，如今守护真相如同守护城墙                     |

## 六大学派

天廷分为六个彼此竞争的学派，每个学派对同一个问题给出了不同的答案：当皇帝不肯开口时，帝国该如何治理？

| 学派     | 核心理念                                                   | 代表人物 |
| -------- | ---------------------------------------------------------- | -------- |
| **正宗** | 延续性是最高的美德。旧制之道维系了帝国四百余年，不毁则不败 | 丹心     |
| **青道** | 帝国必须回归与自然和古老灵性的和谐，而非仅以政令强制执行   | 林间客   |
| **铁算** | 帝国是一台机器。优化这台机器。教条让位于结果               | 铁算     |
| **赤脉** | 血脉记得一切。开国家族建立了这个帝国。他们的遗产不容争辩   | 永夜公   |
| **民火** | 权力自下而上涌动，而非自上而下施舍。帝国属于那些耕耘它的人 | 铁骨     |
| **明镜** | 目的纯正高于一切。帝国必须得到净化，无论代价为何           | 明镜     |

铁壁与夜莺效力于机构而非学派，影子独立交易，天书任职天问局。骨书属于受压制的青道传承，香冠属于万神之庙，逸笔使用多个登记身份。玩家可以为自己的职业另选归属。

## 主持人须知

**主持人法典**是本游戏的秘密引擎。它包含：

- **主持之道**：作为合作伙伴而非对手来主持游戏的原则
- **深层暗流**：天廷权力运作的结构性动力学，完全以游戏世界的语言写成。无需其他语言。其中描述的模式具有普遍性。你若能在其中看到其他语境中的影子，便是读懂了水面之下的东西
- **十二大人物设定**：每位重要角色的声线、身体细节、欲望、恐惧，以及场景种子，另附那个天廷始终没能点清的人
- **主持清和巡察**：游戏标志性场景的四阶段结构、风险表与玩家行动选项
- **战役框架**：三种完整结构（崛起、阴谋、崩塌），附有分幕拆解
- **随机生成器**：二十面骰天廷事件表、十二面骰流言表、人物快速生成器
- **暮染生物图鉴**（见 `host_tools/dusk_bestiary.md`）：从暮染游魂到赤暮化身的生物模板

法典仅供主持人阅读。请妥善保管。

## 会记得选择的残卷

帝国要求人们经由那些已不能诚实描述他们的机构求生。一份恤册，可以从空碗走到工班，从工班走到河流勘图，再走到一项旧承诺，而旧承诺的受益者至今仍在治理。庙中典礼，又会把同一批人带到天廷宣称事情已经了结的地方。

关联不只是一枚反复出现的印。资源会移动，人会记得，衙门须面对先前签下的字，各派会争论什么才是好的回应。政治寓言与宇宙层面的不确定，都被保留；每项大问题，也都有与人相接之处。

初次清和巡察、重修与第七龛，属于这段持续的历史。不更换整批人物，也不推翻前段成果。日皇、肇建与赤暮始终存在于世界，全桌可循已经遇见的证据与关系追问。

主持人法典说明怎样带着后果往前走，战役衔接手册提供共同日程。玩家的问题抵达时，完整叙事与更深的史事仍可查阅。

## 深层暗流

紫宸残卷在两个层面上运行。表层是黑暗奇幻：一个垂死的帝国、一位缺席的皇帝、一种瓦解现实本身的腐化、六个在无尽斗争中彼此绞杀的学派。这个表层是完整且可独立游玩的。

其下流淌着第二道暗流。天廷的内部运作遵循着某些模式，这些模式在任何权力集中并历经数百年僵化的地方都会反复出现。清和巡察的四阶段结构。叙事控制先于并促成其他一切权力形式的方式。已经重复了三百年的积累、矫正、分裂的节律。游戏从未点明这些模式映射了什么。它不需要点明。主持人法典的指引很简单：_你若能在其中看到其他语境中的影子，便是读懂了水面之下的东西。_

每一个政治术语都已被映射为奇幻世界的对等概念。每一个现实世界的制度都已被转译为天廷的语言。加密是完整的。你在深处看到什么，只属于你和你的牌桌。
