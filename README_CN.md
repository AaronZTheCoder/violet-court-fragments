## 关于本作

**紫宸残卷**是一套完整的纸笔桌面角色扮演游戏规则，适合一位主持人与三至六名玩家。你需要的只是骰子、铅笔、打印好的角色档案，以及一张安静的桌子。无需软件。无需屏幕。只需房间里的人，和你们共同构建的世界。

日皇已有约一百六十四年不曾公开开口。天廷依旧以祂的名义统治帝国。六派学说争夺着一个浩瀚到无人能参透其全貌的官僚体系的控制权。边境之外，一种名为赤暮的现实腐化正缓缓吞噬版图，一州接着一州，将良田化为盐碱，将子民化为泣血的空洞躯壳。天廷称之为"局部性失调"，并派出了清和巡察。沦陷的州府从舆图上被抹去。它们从未存在过。

你是一名八品笔吏。你抄录文书。你归档报告。你无足轻重。但帝国是一台将无数微尘碾为齑粉的机器，而这部机器，正在解体。

**这个游戏的主题，从来不是拯救世界。** 而是在一个浩瀚到无人能参透其全貌的古老体制中，挣扎求存。是在压力中缔结、在命运中经受考验的羁绊。是人们为自我辩护而讲述的故事，以及这些故事崩塌时的景象。

表层是黑暗奇幻。深处是为那些懂得阅读的人准备的。

## 快速入门

### 你需要准备

| 物品                     | 说明                                                |
| ------------------------ | --------------------------------------------------- |
| 本规则书                 | 打印 `cn/CORE_RULEBOOK.md` 或 `en/CORE_RULEBOOK.md` |
| 至少一颗二十面骰         | 再加几颗六面骰和八面骰                              |
| 角色档案                 | 每位玩家一份，见 `character_dossiers/`              |
| 主持人法典               | 打印 `cn/HOST_CODEX.md`：仅供主持人阅读             |
| 铅笔和纸                 | 用于记录、追踪，以及那些不可避免的背叛              |
| 3至6名玩家 + 1名主持人   | 理想的牌桌规模                                      |
| 安静的空间和数小时的时光 | 这不是一场三十分钟的游戏                            |

### 你的第一次集会

1. **主持人先读法典。** 从第一部分和第二部分开始。"深层暗流"一章解释了驱动天廷运作的结构性力量。
2. **每位玩家选择一个原型。** 浏览十三份角色档案，选出肖像与真相钩子最能打动你的那一份。仔细阅读你的三项独特能力。你会需要它们的。
3. **一起创建角色。** 按照核心规则书第三章的八个步骤操作。决定你们的角色如何相识。决定谁欠谁什么。
4. **运行"初次清和巡察"。** 建议从 `the_first_harmonization_cinematic_cut.md` 开始；这是一部可供四至六次集会完整游玩的电影化长篇模组，主持人可以直接开场。游玩时可同时打开完整制作资料库，查阅扩展遭遇、原型内容与机制细节。
5. **让战役自然展开。** 入门模组结束后，使用主持人法典中的战役框架（崛起、阴谋、崩塌）、随机事件表和人物生成器，构建后续的故事。

## 六大学派

天廷分为六个彼此竞争的学派，每个学派对同一个问题给出了不同的答案：当皇帝不肯开口时，帝国该如何治理？

| 学派     | 核心理念                                                   | 代表原型 |
| -------- | ---------------------------------------------------------- | -------- |
| **正宗** | 延续性是最高的美德。旧制之道维系了帝国四百余年，不毁则不败 | 炼金术士 |
| **青道** | 帝国必须回归与自然和古老灵性的和谐，而非仅以政令强制执行   | 精灵     |
| **铁算** | 帝国是一台机器。优化这台机器。教条让位于结果               | 工程师   |
| **赤脉** | 血脉记得一切。开国家族建立了这个帝国。他们的遗产不容争辩   | 吸血鬼   |
| **民火** | 权力自下而上涌动，而非自上而下施舍。帝国属于那些耕耘它的人 | 狼人     |
| **明镜** | 目的纯正高于一切。帝国必须得到净化，无论代价为何           | 圣武士   |

骑士与刺客立于各派之间。游荡者立于各派之外。法师立于各派之上，静观其变。德鲁伊从来不在六派的计数之内，而女祭司属于一个比这六派都更古老的东西。变数被其中四派清点过，用的是四个不同的名字，而这四派没有一派想明白，他们点的是同一个人。

## 主持人须知

**主持人法典**是本游戏的秘密引擎。它包含：

- **主持之道**：作为合作伙伴而非对手来主持游戏的原则
- **深层暗流**：天廷权力运作的结构性动力学，完全以游戏世界的语言写成。无需其他语言。其中描述的模式具有普遍性。你若能在其中看到其他语境中的影子，便是读懂了水面之下的东西
- **十二大人物设定**：每位重要角色的声线、身体细节、欲望、恐惧，以及场景种子，另附那个天廷始终没能点清的人
- **主持清和巡察**：游戏标志性场景的四阶段结构、风险表与玩家行动选项
- **战役框架**：三种完整结构（崛起、阴谋、崩塌），附有分幕拆解
- **随机生成器**：二十面骰天廷事件表、十二面骰流言表、人物快速生成器
- **暮染生物图鉴**（见 `host_tools/dusk_bestiary.md`）：从暮染游魂到赤暮化身的生物模板

法典仅供主持人阅读。请妥善保管。

## 深层暗流

紫宸残卷在两个层面上运行。表层是黑暗奇幻：一个垂死的帝国、一位缺席的皇帝、一种瓦解现实本身的腐化、六个在无尽斗争中彼此绞杀的学派。这个表层是完整且可独立游玩的。

其下流淌着第二道暗流。天廷的内部运作遵循着某些模式，这些模式在任何权力集中并历经数百年僵化的地方都会反复出现。清和巡察的四阶段结构。叙事控制先于并促成其他一切权力形式的方式。已经重复了三百年的积累、矫正、分裂的节律。游戏从未点明这些模式映射了什么。它不需要点明。主持人法典的指引很简单：_你若能在其中看到其他语境中的影子，便是读懂了水面之下的东西。_

每一个政治术语都已被映射为奇幻世界的对等概念。每一个现实世界的制度都已被转译为天廷的语言。加密是完整的。你在深处看到什么，只属于你和你的牌桌。
